FlowAssist AI - Multi-Agent IT Support Automation
Overview
FlowAssist AI is an intelligent IT support automation platform that combines LLMs, retrieval systems, automated remediation, and ticket escalation workflows to diagnose and resolve technical issues.

System Architecture
User ↓ Response Cache ↓ Planner Agent ↓ Knowledge Agent (BM25) ↓ Runbook Engine ↓ Endpoint Agent ↓ Remediation Agent ↓ Judge Agent ↓ Ticket Escalation
